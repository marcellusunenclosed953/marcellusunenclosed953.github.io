✅ What Is This?

pub-excavator-openscad is a complete digital toolkit for building your own mini excavator. It's a single intelligent 3D model file that you can customize, and it automatically generates everything you need to build the real machine:

  • Detailed engineering drawings you can print or send to a maker shop
  • A complete Bill of Materials (BOM) listing every screw, bolt, and part
  • Kinematics calculations showing exactly how the boom, stick, and bucket will move
  • Strength reports to help you understand load limits
  • An interactive 3D browser viewer so you can spin and inspect your excavator design before building

Even if you're not an engineer, this tool makes it possible to create a real, working excavator from your computer. You just adjust a few sliders, and the system handles the math.

📐 What Will You Find Inside?

Complete Design Package

  • The core parametric OpenSCAD file (one single .scad file)
  • Pre-configured design presets for popular bucket sizes
  • DXF outline files for cutting steel plates with CNC or laser cutter
  • STEP/IGES exports for use in other CAD programs

Generated Reports

  • Full kinematics report (PDF) — shows reach, angles, and pivot points
  • Stress analysis output — approximate force maps for key components
  • Bill of materials (BOM) with part numbers and suggested suppliers

All outputs are organized into clean folder structures — drawings, cut_files, reports, and 3d_print.
